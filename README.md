# Python-Based Web Scraping & Data Analysi

## Project Overview
A Python-based web scraping and data analysis project using the Books to Scrape website. Collected 1,000 book records from 50 pages and performed data cleaning, feature engineering, and exploratory data analysis (EDA).

## Technologies Used
- Python
- Google Colab
- Requests
- BeautifulSoup
- Pandas
- Matplotlib
- Seaborn

## Key Features
- Web scraping of 1,000 book records
- Data cleaning and preprocessing
- Feature engineering (Rating Category and Price Category)
- Exploratory Data Analysis (EDA)
- Data visualization and statistical analysis
- Exported dataset in CSV and Excel formats

## Dataset Information
- Total Records: 1,000
- Total Features: 6
- Missing Values: 0
- Average Book Price: £35.07

## Project Files
- Jupyter Notebook (.ipynb)
- Dataset (.csv)
- Dataset (.xlsx)
